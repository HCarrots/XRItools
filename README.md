# XRI

C++17 / Qt 6 Widgets / HDF5 编写的 Windows 和 Linux 同步辐射数据浏览、谱学处理与三维成像软件。

本项目源代码采用 [MIT 开源协议](LICENSE)发布，Copyright (c) 2026 Hu Shiqi。第三方组件遵循各自许可证，详见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 运行

Windows 便携包完整解压后运行 `XRI/XRI.exe`。Linux 安装包安装后从应用菜单打开 XRI，或在终端运行 `XRI`。使用“文件 → 导入 HDF5 文件”多选，或拖入多个 `.nxs` / `.h5` 文件。

在“语言 / Language”菜单选择“简体中文”或“English”。XRI 会保存设置并自动重启，然后重新打开已导入的数据文件。若有任务在运行，请等任务结束后再切换。

如果 Windows PowerShell 提示禁止运行脚本，先在当前窗口执行 `Set-ExecutionPolicy -Scope Process RemoteSigned`。关闭该窗口后，进程级设置自动失效。

在项目目录运行脚本。它会从 `workspace\Data` 或旧的 `Data` 目录打开 15469 测试扫描，缺少测试文件时直接打开 XRI。

```powershell
.\scripts\run.ps1
```

可通过 `-File` 指定扫描，或直接调用程序来指定初始数据集和帧号。

```powershell
.\scripts\run.ps1 -File .\workspace\Data\15469_grid_scan_20261014231918_1.nxs
.\dist\XRI\XRI.exe .\workspace\Data\15469_grid_scan_20261014231918_1.nxs --dataset /entry/data/D_LAMBDA --frame 1000
```

## 界面工作流程

菜单栏为 **文件｜数据浏览器｜ROI｜谱学｜成像｜IXS衬度成像｜语言｜帮助**。展开 **ROI** 菜单可在主窗口内切换手动选取和自动选取工作区。

通过 **文件 → 指定工作区** 选择一个路径不含中文的文件夹。XRI 会记住该路径，并将保存的配置和结果自动写入以下目录。

| 功能        | 配置或可复用方案      | 结果                                                      |
| ----------- | --------------------- | --------------------------------------------------------- |
| ROI         | `ROI/config`          | `ROI/results`（自动识别掩膜与参数）                       |
| 谱学        | `spectroscopy/config` | `spectroscopy/results`（原始谱、调整后 ROI 和扣背底结果） |
| 成像        | `imaging/config`      | `imaging/results`（重建目录与旋转 GIF）                   |
| IXS衬度成像 | `ixs/config`          | `ixs/results`（四维 HDF5 和诊断 PNG）                     |

自动生成的名称会尽可能保留源扫描文件名中的英文和数字，并加上操作名称和时间。重复保存会生成新文件或目录。首次指定工作区前，保存时可手动选择位置。

1. **导入与浏览**。文件菜单可多选 HDF5。「从数据库导入HDF5文件」会在指定目录及其子目录中查找 HDF5 和 NeXus 文件。列表显示文件名和相对目录，按 Ctrl 点选或 Shift 连选，再点击「导入所选文件」。弹窗显示扫描状态和导入进度。浏览器保留各文件的数据集、帧、坐标轴和显示方式。
2. **ROI**：75 晶体框选、批量失效、实时 X/Y 剖面集中在同一编辑器。同一文件复用编辑状态；处理页的“选取 ROI”返回后同步方案。查看而未修改 ROI 不会清空谱学标定；修改后会使相关旧结果失效。
3. **谱学**：数据与 ROI → 掩膜与谱分辨 → 弹性标定 → XRS 与 I0 → 原始谱结果 → Compton 峰分析 → 背景分析 → 近边结构结果分析。
4. **成像**：文件与 ROI → 重建参数 → 输入与标定检查 → 剖面分析 → 三维模型 → 日志。校验后在检查页运行重建；配置与已有结果入口集中在文件准备页。
5. **IXS衬度成像**：校验数据与 ROI → ROI标定 → 筛选晶体 → 四维体素重建 → 体素谱与三维结果分析。

各处理页选择数据时，可直接使用浏览器已导入的文件。左侧文件结构面板只在浏览时显示，返回后恢复原状态。

全部交互图表与成像诊断 PNG 共用学术刻度：1/2/2.5/5 主刻度、次刻度、四边内向刻度、统一数字精度；谱学实验曲线采用白底黑框、连线和小加号，图例放在上方数据点较少的一侧。单次扫描的小加号对应实测能量点，拼接、插值或叠加谱的小加号对应其输出能量网格。拟合和理论参考以线型区分。二维图像默认无网格；图上右键可切换网格与次刻度、复位范围。对数显示使用原始量值标注刻度，零和负值均保留。显示样式不改变积分、拟合或重建结果。

## 功能

根据完整文件名区分扫描格式，并在窗口标题、文件树根节点和数据摘要中显示：

| 文件名规则                                 | 识别类型             | 当前示例                                          |
| ------------------------------------------ | -------------------- | ------------------------------------------------- |
| `<编号>_scan_<14位时间戳>_<序号>.nxs`      | scan · 一维扫描      | `14516_scan_20260917142117_1.nxs`（51 帧）        |
| `<编号>_grid_scan_<14位时间戳>_<序号>.nxs` | grid_scan · 网格扫描 | `15469_grid_scan_20261014231918_1.nxs`（7056 帧） |

匹配不区分大小写，仅使用文件名，不受目录名影响。不符合规则的文件显示为“通用 HDF5 / NeXus”，仍可浏览。两种格式共用 HDF5 按需读取，维度与帧数以文件内容为准；打开新文件从第 0 帧开始。

- 中英双语 Qt Widgets 菜单、文件对话框和可停靠面板。“文件”集中管理导入、导出副本和关闭，“数据浏览器”集中管理预览方式、图表复位与文件结构面板。
- 按层展开 HDF5 分组，显示数据类型、维度和属性；筛选当前已加载节点。
- 标量、字符串、布尔、一维信号、二维图像和多维数组切片。
- 自由选择 X/Y 维度；底部滑块与帧输入框控制首个固定维度，支持播放。其他固定维度默认使用索引 0。
- 后台只读读取，快速切换时丢弃过期结果；探测器只读取当前帧。
- 白底学术图表、内向刻度、Viridis / Inferno / 灰度、等比例、保留符号的 log1p 显示。
- 滚轮缩放、双击复位、鼠标数值提示；显示当前切片的 min/max/mean/sum。
- 虚拟数值表，按需查看当前切片的数值。

索引从 **0** 开始。图像原点在左上，Y 向下；坐标使用数据集维度索引。

多个文件同时保留在左侧“文件列表与结构”中，每个文件有独立树根；点击其中的数据集或用“当前文件”下拉框切换。切换时恢复上次查看的数据集、坐标轴、帧索引和预览页。重复导入同一路径不会增加重复文件，重新定位到默认数据集第 0 帧。关闭当前文件后自动转到另一个已导入文件，也可关闭全部。

“文件 → 导出当前文件副本”按完整原始字节导出 HDF5 / NeXus，保留全部维度与元数据；不使用屏幕采样预览替代原数据。导出在后台分块执行，可取消；成功才提交最终文件，任何已导入的原文件均不能作为导出目标。此处为整文件副本，先前移除的图表及切片 CSV 导出保持移除。

命令行也接受多个文件，最后一个作为当前文件：

```powershell
.\dist\XRI\XRI.exe .\workspace\Data\14516_scan_20260917142117_1.nxs .\workspace\Data\15469_grid_scan_20261014231918_1.nxs
```

## 第一步：75 个分析晶体的 ROI 选取

导入文件后，选择“ROI → 手动选取 ROI”，针对当前浏览文件操作；scan 和 grid_scan 共用同一个 ROI 模块。scan 的后续处理位于“谱学”菜单；grid_scan 的薄膜标定与三维联合反演位于“成像”菜单。

按参考 notebook 中的探测器分配，LAMBDA 包含 VB、HL、VU、HB 四个模块，共 60 个晶体；MINIPIX 包含 VD 模块，共 15 个。每个模块使用 A1、A2、A3 … E1、E2、E3 的标准唯一编号。参考 notebook 的历史输出中存在重复 VU 名称，本程序不复用这些重复项，也不自动将旧坐标当作已选结果。

1. 默认显示两台探测器的**全部帧原始计数叠加图**；可切换单帧，并开启 signed log1p 显示弱信号。大文件逐帧读取，不加载完整三维数组。
2. 在右侧选择晶体，然后在对应探测器图像上拖动框选。支持反向拖动、滚轮缩放、双击复位和 Esc 取消当前拖动；框选后显示晶体标签，默认跳到下一个未设置项。
3. 可修改 x1、x2、y1、y2 后点击“应用坐标 / 设为有效”；边界必须在图像内，坐标规则与 Python 切片相同：`image[y1:y2, x1:x2]`，右侧和下侧不包含在内。
4. 无法框选的晶体可用 **Ctrl 多选、Shift 连选、Ctrl+A 全选**，再点击“批量标记失效（数量）”。支持跨探测器选择；批量操作后保留所选行，已有矩形也保留，保存时 `add=false`。单选时仍可逐个标记失效并自动跳到下一项。框选、坐标编辑和“清除重选”仅作用于单选晶体。
5. 每次修改会自动保存到应用本地数据目录 `roi-drafts` 下，按原文件路径分别保存。再次打开同一文件的 ROI 窗口可继续编辑。也可“保存 ROI 方案”到独立 `.roi.json` 文件；尺寸相同的探测器可通过“加载 ROI 方案”在 scan / grid_scan 之间复用。加载会检查 75 个编号、探测器对应关系、尺寸和坐标，失败时保留当前方案。
6. 全部 75 个晶体都处于有效或失效状态后，“完成 ROI 选取”按钮才可用。

勾选窗口顶部“显示 X/Y 剖面图”，可选择探测器并输入 X（列）、Y（行）：横向剖面为 `image[Y, :]`，纵向剖面为 `image[:, X]`。直接拖动蓝色竖线调整 X、横线调整 Y、交点调整两者，坐标和曲线在拖动过程中实时更新；也可按住 Ctrl 在任一探测器图像中单击或拖动定位。Esc 停止拖动，拖出图像时位置限制在有效像素范围。远离定位线的普通拖动仍用于框选 ROI。也可单选一个已有 ROI 后点击“定位到当前 ROI 中心”。坐标范围随探测器尺寸变化，单帧切换后剖面同步更新。剖面默认显示原始计数，可独立切换对数显示；这仅改变显示比例，不改变数值，也不进行区域积分或修改晶体 ROI。

本步骤只保存矩形坐标与人工有效性标记，不执行 I0 归一化、自动寻峰、阈值掩膜、ROI 积分、拟合或成像重建。原始 `.nxs` 始终只读。先前删除的通用数据检查器、水平积分及图表/CSV 导出功能保持移除。

### 文本式 ROI 转换

选择「ROI → 文本式ROI转换」，可一次选中 LAMBDA 和 MINIPIX 的旧 `.txt` 或 `.tsv` 表，合并保存为共用的 `.roi.json`。坐标沿用右侧和下侧不包含的切片约定，并应用表中的平移和扩展。程序优先读取当前文件的探测器尺寸，缺少尺寸时使用 LAMBDA 516×516、MINIPIX 256×256。缺失、全零或明确停用的晶体标为失效，可在手动 ROI 编辑器里重新选取。识别到旧版 VU 布局时应用已记录的映射，越界上限裁到探测器边界，转换记录随方案保存。指定工作区后，方案保存到 `ROI/config`。

选择「ROI → JSON 转旧版 ROI 文本…」，打开共用 ROI 方案并选择输出目录。程序在新建的子目录中按探测器保存 `roi_lambda.txt` 和 `roi_minipix.txt`，仅导出有效晶体，保留各探测器内的旧版编号和右侧、下侧不包含的坐标。非矩形掩膜须确认后才按外接矩形导出。没有有效晶体的探测器跳过。

### 自动识别光斑 ROI

在数据浏览器中导入并选中 NeXus 文件，打开“ROI → 自动选取 ROI”，选择探测器以及单帧或全部帧叠加，并在“识别参数”中指定 Python 环境与训练权重。识别后，左侧显示带编号的掩膜叠加图，右侧显示识别结果。导出的 JSON 保存每个光斑的掩膜、扣除局部背景后加权的质心、原始积分、净积分和等二阶矩椭圆参数。坐标按零起始的 X 列、Y 行表示，掩膜以行优先的 `[start,length]` 像素段保存。光斑按质心排序编号，晶体归属需结合标定核对。

点击“匹配晶体”使用本次结果，或点击“载入识别结果”使用已保存的结果。先在右侧选晶体，再在左侧点对应光斑的着色掩膜。可清除、标记失效或设置后跳到下一个未设置的晶体。既可以从空白方案开始，也可以载入已有方案继续编辑。处理第二个探测器时，载入第一次保存的方案即可把两台探测器的匹配合并。允许保存待设置的晶体，开始分析前按模块提示补齐或标记失效。

确认后保存为共用 `.roi.json`，可直接在谱学、成像和 IXS衬度成像载入。模块按掩膜从所选扫描逐帧取像素，再执行各自的归一化、标定和处理。谱学的寻峰重定位和强度阈值仅应用于矩形 ROI，重叠像素选项仍照常应用。旧矩形方案仍可载入。

为该功能创建独立 Python 环境，并在该环境内安装推理依赖。以下命令安装 CPU 版本。

```sh
python -m pip install torch==2.10.0 torchvision==0.25.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install numpy scipy h5py
```

训练脚本在线生成圆形与椭圆光斑、泊松噪声、背景梯度和热像素。可用真实标注的 NPZ 微调，每个 NPZ 包含 `image[H,W]` 和 `masks[N,H,W]`。也可用 `--real-scan` 与 `--roi-boxes` 在既有晶体框内提取弱标注。

```sh
python scripts/roi_maskrcnn.py train --synthetic 2400 --output roi-synthetic.pt
python scripts/roi_maskrcnn.py train --synthetic 0 --resume roi-synthetic.pt --fine-tune 400 --real-masks annotated.npz --output roi-maskrcnn.pt
```

官方发布包已附带 `roi-maskrcnn.pt`，在识别窗口选择装有推理依赖的 Python 可执行文件即可。自行训练的权重也可在同一窗口选择。Linux CMake 打包时可通过 `-DXRI_ROI_MODEL=/path/to/roi-maskrcnn.pt` 附带权重。

## 第二步：谱学处理

“谱学”菜单进入同一个主窗口工作区，通过八个步骤页处理数据，切换工作区后参数与结果仍保留。算法按提供的 `data_processing_v4.py` 与 `XRS_DataAnalysis20261013.ipynb` 中的弹性标定、掩膜、I0 修复、XRS 提取、Q 计算及插值叠加流程实现，使用原生 C++，运行无需 Python。

「1 数据与 ROI」右侧点击「新建分组」，选择元素和目标壳层，自动生成名称，例如 `O_K`、`Ni_L3` 或 `Ni_L23`。选择分组后，通过「添加扫描 → 从数据浏览器多选…」批量添加 XRS 扫描，也可从磁盘选择多个文件。在当前分组的扫描列表中，用 Ctrl 多选或 Shift 连选，再右键批量勾选或取消勾选。新分组继承当前的弹性参考、ROI 和参数，扫描列表及宽谱文件从空白开始。一个方案 JSON 保存所有分组的目标元素边及各自的参考文件、扫描、ROI 与掩膜、标定、叠加、宽谱、背景分析参数和最近保存路径。旧版单组方案会载入为 `Default` 分组。

有 Compton 测量时，展开「1 数据与 ROI」左侧的「高级」，勾选「测量 Compton」。这会启用第 6 步，并勾选第 7 步的 HF-core、Compton 峰拟合背景和非对称函数修正。可以按需取消各项。进行 HF-core 拟合时，填写「元素与化学比」，并使用内置 DABAX `ComptonProfiles.dat` 或选择自定义 HF 壳层表。新建分组时，所选的元素和壳层同时成为该组默认扣除项，例如 `O:K`。拟合时按当前 HF 表解析壳层，内置表的 `Ni:L3` 对应合并的 `L2,3` 轮廓。右侧「选壳层」显示实际匹配的轮廓及结合能，也可手动调整该组设置。测量选项、组分、HF 表和扣除项均随各组写入方案。

组表显示未处理、已叠加、部分完成或已完成。第 7 步完成所选目标的背景扣除后标记为已完成。切换分组或重新载入方案可查看上次处理状态并按各组配置重新计算。在工作区保存时，方案名使用样品名，原始谱目录和近边结构结果文件名还包含元素边，例如 `sample_O_K_raw_…` 和 `sample_O_K_near_edge_…`。留空的样品名使用弹性扫描名。

修改计算参数后，受影响页面的 **下一步** 和后续页签会禁用。先进入受影响的页面，点击该页的计算按钮。计算成功后即可继续。Compton 页按测量方式使用 **使用 Full Scan** 或 **Compton 峰拼接**，背景分析页使用 **批量扣除** 或 **使用原谱**。待手动计算的状态随元素边分组一起保存。仅切换预览谱或显示能区可直接进行。

1. **数据与 ROI**：选择弹性参考 scan，读取该文件的ROI 草稿，或载入尺寸匹配的 `.roi.json` 方案。75 个晶体均须完成框选或标记失效。添加多个 XRS 扫描，取消勾选可剔除整次扫描。grid_scan 会明确拒绝用于一维谱学处理。
2. 在 **1 数据与 ROI** 点击 **下一步**，程序进入掩膜页。参数掩膜支持 ROI 峰值重定位、方形窗口大小、逐晶体 X/Y 偏移与扩展，以及阈值筛选（默认严格大于 ROI 叠加图最大值的 15%）。自动重定位默认关闭，重叠像素剔除默认启用。调整参数后，可点第 2 步底部的 **计算掩膜** 从原始 ROI 重新生成参数掩膜。点击 **重置掩膜** 可清除已应用的参数掩膜和谱分解掩膜，让后续弹性标定与谱提取使用载入时的原始 ROI。可随时用保留的参数重新计算掩膜。掩膜页显示弹性叠加图、最终像素掩膜和 ROI 标注，操作状态显示在主窗口底部。
3. **弹性标定**页左侧显示弹性谱，右侧显示晶体拟合表，中间分隔条可拖动。可点击 **计算弹性峰** 重新拟合，查看每个晶体原 ROI / 掩膜谱、拟合曲线、峰位、FWHM、R² 及未通过原因；也可查看全部合格谱的零点对齐。支持 Lorentzian 或 Gaussian 加常数背景，默认中心 9.67–9.69 keV、FWHM ≤ 2 eV、R² ≥ 0.8。失效、无像素、平坦或未收敛的晶体不会进入叠加。
在 **2 掩膜与谱分辨** 中点 **像素谱分解…**。选择具有样品特征的参考 XRS 扫描（可以和待提取的扫描不同），然后分解当前晶体或点 **分解全部晶体**。默认方法为 NNMF，也可选 PCA 或 ICA。能量轴为入射能量，参考扫描沿用 XRS 的 I0 和坏点修复设置。使用晶体列表或 **上一个晶体 / 下一个晶体**（Alt+← / Alt+→）切换时，弹窗直接打开本次已计算的预览。更换参考扫描、方法或组分数后，需重新分解。

根据谱形选择目标组分，并比较协方差、保留像素图和积分谱。默认阈值为最大正协方差的 0.2 倍，也可输入绝对阈值。用保留像素再分解可逐轮缩小 ROI。点 **批量采用所选组分** 可以对待确认的晶体使用同一组分编号、阈值和符号，尚未分解的晶体会先计算。组分编号对应各晶体自己的分解序号，同编号的谱形可能不同。无可用组分的晶体保留原 ROI，计算失败或阈值下无像素的晶体可单独确认。也可逐个点 **采用所选组分** 或 **不采用，保留原 ROI**，并调整已确认的选择。全部有效晶体确认后，点 **应用谱分解掩膜**。此时所有像素掩膜参数暂停生效，未采用组分的晶体直接使用原 ROI。修改参数并点 **计算掩膜**，成功后会用参数掩膜替换谱分解掩膜。方案分别保存原始 ROI 和已应用的谱分解结果。在第 2 页点 **下一步** 可使用当前掩膜计算弹性标定，通过 **保存调整后 ROI…** 可导出当前像素方案。方法见 [Sahle 等人，图 3](https://journals.iucr.org/s/issues/2017/01/00/hf5329/index.html)。

4. 点击 **提取 XRS**：逐帧积分原 ROI 与掩膜。弹性和 XRS 的 `|I0|` 归一化可分别开关。XRS 归一化开启时，可在第 4 页设置 **最小跌幅**（默认 5%）。程序从原始 |I0| 识别比左右两侧分别下降超过阈值的孤立低点，也可修复夹在两个有效邻点间的单个缺失读数。按实测入射能量对 I0 和对应探测器帧做线性插值，再归一化。修改设置后点击 **提取 XRS** 重新计算，图中圆圈标出修复位置。“XRS 与 I0”页可切换扫描和晶体，检查修复前后 I0 及提取谱；掩膜页可查看当前 XRS 扫描的叠加图。
5. **原始谱结果**页中央显示谱图，右侧为晶体选择表。拖动分隔条可调整两侧宽度，点击最左侧参数面板旁的箭头可收起或展开参数。角度可从弹性文件、首个 XRS 文件读取，或手动填写（degree）。几何默认晶体口径 100 mm、距离 1070 mm、晶体间隔 7°。按模组、平均 Q 范围筛选；Ctrl/Shift 多选晶体后可批量排除或纳入，人工失效及拟合未通过项无法重新纳入。
6. 点击 **计算 Q 并叠加**：按各晶体拟合中心计算 `能量转移 = (实测能量_keV − 峰位_keV) × 1000`。在所有参与曲线的共同范围内按指定步长（默认 0.2 eV）线性插值，先按晶体叠加多次扫描，再求模组谱及总谱。支持升序、降序和不等间隔能量轴。曲线选择器可查看总谱与各模组、各模组谱、全部单晶体谱、单个模组谱，以及单晶体的各扫描与叠加对比。用选择器旁的左右箭头切换上一条或下一条。
7. 点击 **保存谱学结果**，选择父目录后创建独立时间戳目录，包含 `spectrum_data.txt`（总谱及模组）、`spectrum_all_data.txt` 和各晶体文本谱、`spectrum_rois.txt`（拟合和 Q/dQ 表）、原始及调整后的 ROI JSON、实际像素掩膜及处理参数/能量通道/I0 修复记录。写入完成后才重命名为最终目录，已存在的目录不会覆盖。

能量输入单位为 **keV**，能量转移和 FWHM 为 **eV**，Q/dQ 为 **Å⁻¹**。`auto` 优先读取 `/entry/instrument/M_DCM_B5Energy`，缺失时使用 `M_DCM_B5Energy_readback`；也可输入完整能量/I0 数据集路径。I0 默认 `/entry/data/D_SiC_Current1`。未开启归一化时无需 I0 数据；开启后不可修复的零值或非有限值会报错。单调性、探测器尺寸、帧数与能量长度均检查，不自动合并重复能量点。

与旧程序的数值处理差异：拟合失败会明确排除，不沿用初始参数；Q 计算使用每个晶体的拟合弹性能量；公共插值范围仅由实际参与叠加的合格曲线决定，边界向内取整，避免外推。多扫描与晶体均**求和，不取平均**。改变弹性参数会清除后续结果，改变扫描或归一化只要求重新提取，改变筛选条件只要求重新叠加。计算在后台执行，支持取消。

当前真实 scan 与已有 ROI 方案已验证弹性标定；多扫描 XRS 的完整流程通过已知解析谱的合成 NeXus 数据验证。真实样品 XRS 扫描需由用户添加后再处理。

使用 **下一步** 连续处理时，程序沿用界面参数，依次生成掩膜、标定弹性峰、提取 XRS 与修复 I0、计算 Q 并叠加。第 6 步点击 **下一步** 将完整谱传入第 7 步。第 7 步逐项拟合已启用的背景，确认图形后点击「批量扣除」，再进入第 8 步查看结果。

**6 Compton 峰分析**。**Full Scan** 直接沿用第 5 步的逐晶体谱、能量轴和几何。**独立测量**可在「选择宽谱文件」中从数据浏览器或磁盘载入原始 NeXus 宽谱或已处理的逐晶体宽谱，再点「Compton 峰拼接」。拼接成功后可点击 **下一步** 进入第 7 步。原始扫描沿用第 3 步的弹性标定和 ROI，按各晶体的弹性峰换算能量转移。

拼接使用两套谱中同名且强度单位一致的晶体。近边谱覆盖的能区保留近边实测点，替换该区间中的宽谱点。两段相离时按能量排序直接合并，空档保留为空。各晶体的拼接结果保留实测能量与强度，拼接过程不插值、不外推。

第 6 步左侧设置测量方式、预览谱和预览能区，右侧显示谱图、采样统计和拼接摘要。「预览谱」可选总谱、模组谱和单晶体谱。总谱和模组谱预览在各晶体的共同覆盖内对齐相邻点后求和。「限定预览能区」只影响显示。勾选「近边谱按扫描次数归一化」时，近边谱的预览和拼接都使用第 5 步叠加强度除以实际扫描次数后的平均值。

第 5 页保存的 `spectra.h5` 含逐晶体强度、平均 q、分析器能量和散射角。外部 HDF5 可在“外部 HDF5 数据集映射”中指定强度、能量和标签路径。也可载入 `xrs_ana` 的 `*_all_data.txt`，由同名 `*_rois.txt` 文件提供晶体几何。宽谱缺少的几何参数从第 5 步的同名晶体补齐。

**7 背景分析**。未勾选「测量 Compton」时，第 5 步的原始谱直接进入此页。勾选时，输入来自第 6 步的 Full Scan 或 Compton 拼接谱。选择分晶体、模组谱或总谱，指定要预览的谱。默认启用一阶多项式背景。四项全部启用时，按多项式背景 → HF-core → Compton 峰 → 非对称修正的顺序在上一项扣除后的残差上逐项拟合。模组谱和总谱可用多项式背景与 Compton 峰两项。对于逐晶体能量轴不同的原始宽谱，模组谱和总谱在共同覆盖内分别对齐近边区前后的宽谱点后求和，拼接空档保持为空。关闭所有背景项后，点击「使用原谱」，再通过「下一步」查看和导出选中的原谱。

每项可设置自己的拟合能区，多段用逗号分隔，例如 `120:200, 320:450`。可设置共用的「保护能区」，让各项拟合跳过目标近边结构所在的数据点。多项式背景可选 0–6 阶。旧配置中的线性背景会按一阶多项式恢复。Compton 峰拟合使用零常数项的对称 Pearson VII。HF-core 使用第 1 步当前分组的壳层表、元素与化学比、扣除壳层，以及该晶体的散射几何生成芯谱模板，并拟合一个非负的总比例。非对称项在该晶体的电子动量 `pz` 上使用奇函数 `tanh(pz/rise) * exp(-(pz/decay)^4)`，可调上升与衰减宽度，并拟合带符号的幅度。拟合范围应覆盖 `pz=0` 两侧。

每完成一项拟合，图中会在输入谱旁加上背景分量，有多项时也显示总背景。扣除后的谱在第 8 步查看。「预览谱」旁的左右箭头可切换到相邻的谱，修改上游设置会使它及后续分量待重新拟合。当前预览谱的启用项全部拟合后，展开「批量目标」选择处理对象，再点击「下一步」左侧的「批量扣除」。每条谱按相同的顺序和能区独立拟合。参数栏可收起，失败的目标可在对应谱的预览下查看原因。

**8 近边结构结果分析**。结果谱选择器沿用第 5 步的浏览方式，并可通过左右箭头快速切换。分晶体处理后，可查看总谱与各模组、各模组谱、全部单晶体谱及单条谱。模组和总谱按已完成处理的目标求和，同时可另选全部晶体或分组等权平均。第 7 步按模组或总谱处理时，第 8 步显示对应层级的结果。单条谱视图可切换原谱与背景分量。「谱图设置」下方的「谱平滑」可在同一张图中叠加 Savitzky–Golay 平滑曲线和未平滑的结果谱，默认使用 7 个点和二阶多项式。平滑按实际能量坐标拟合，缺失点和拼接边界两侧分别处理。当前能区可保存为 HDF5 或制表符分隔的 UTF-8 文本（`.txt`）。平滑用于绘图对比。两种格式均保存所选处理目标的能量、未平滑的输入强度、各背景分量、总背景和扣除后强度。HDF5 还保存拟合参数，文本以 `nan` 表示缺失值。

## 成像：薄膜标定与三维联合反演

三维成像和 IXS 衬度成像优先载入工作区的 `Data/kapton/target_kapton_55.nxs`，使用 0.5 s 薄膜曝光、0.05 mm 厚度、`D_LAMBDA`、`D_SiC_Current1` 和文件内的扫描循环。工作区有 `ROI/config/legacy-v4.roi.json` 时也会预填该 ROI 方案。两条流程共享 `imaging/calibration-cache` 中的薄膜光斑响应和空间模型。换样品或筛选晶体后可复用缓存，样品信号和相对增益仍按当前设置计算。导入其他薄膜，或修改 ROI 几何、采集设置与光斑拟合参数后，会为新的配置计算标定。启用能区匹配时按当前样品能区计算薄膜响应。

Windows 便携目录和 Linux 安装包随附 `target_kapton_55.calibration.h5` 与配套 ROI。工作区缺少原始扫描时，两条流程直接使用随附的预计算空间响应和模型。预设约 18 MB，包含响应、计数方差、ROI 坐标和晶体光斑模型。使用不同的 ROI 几何、采集参数或能区匹配时，请导入原始薄膜 NeXus 生成标定。

在“文件与 ROI → 采集与物理尺度 → 扫描循环与各层帧数”中，分别设置样品的 Y、Z、DCM 和薄膜的 X、DCM。顺序从外到内排列，各轴帧数表示该轴每次循环的扫描点数。默认读取文件计划。手动顺序需与文件计划一致，手动点数按扫描范围和逐帧坐标校验。“每批读取帧数（缓存）”独立控制读取批次。循环设置随 JSON 配置保存，输入检查页显示实际顺序、各轴点数与总帧数。

打开“成像 → 打开成像处理工作区”，可导入旧 Python XRI 的 JSON 配置，或手动设置薄膜 NeXus、样品 NeXus、ROI 和采集参数。相对文件路径按配置文件所在目录解析。原配置路径若已移动，请在界面浏览选择当前文件。指定工作区后，每次重建都会生成新的输出目录。手动保存时需要选择一个尚不存在的输出目录。

如果源码目录的 `examples/` 中包含 `imaging.15469.json` 或 `DT_Be_ROI.txt`，部署脚本会将它们复制到程序旁。使用旧示例配置时，请在界面选择当前的原始文件和 ROI 表。

1. **文件与 ROI**：支持旧 TSV ROI 表、显式排除编号/标签修正，以及当前软件的共用 `.roi.json` 方案。“选取ROI”复用现有框选界面；人工失效保持排除。只使用明确选择的探测器，固定像素，不做谱学自动寻峰或阈值掩膜。
2. **重建参数**：新方案默认启用「用薄箔留出误差自动选择模型」。每块晶体逐个留出薄箔位置，使用其余位置重新拟合，预测留出位置的整个 ROI。按所有留出图像合并的相对 L2 误差选择恒定高斯、幅度和双轴宽度随 X 缓慢变化的高斯，或沿质心轨迹对齐的实测模板插值。评分包含从训练位置估计的标定背景；样品正演使用光斑信号。模板要求至少 8 个合格位置、中心反射不对称指标的中位数达到 0.12，且至少有 3 次区间内模板预测。若留出后某轮无法标定，整块晶体保留高斯基线。关闭开关可沿用固定高斯。曝光、I0、箔厚、网格、增益及求解器参数仍可单独设置。

   在「日志 → 光斑模型与质心轨迹」切换晶体，可查看采用模型及留出误差。打开已有重建后，点击「用已有标定比较模型」即可用保存的薄箔像素重新评分，并将结果写入 `psf_model_comparison.json`。新方案执行完整重建时会将选中的模型用于正演矩阵，并在 `psf_models.json` 保存逐位置的像素 RMSE。深度分辨率验证会在每轮剩余的薄箔数据中重新选模。

   **计数方差与背景**位于「2 重建参数」。常规成像默认使用未加权 NNLS。启用方差加权后，晶体增益、非负求解和三维 TV 共用逐像素、逐 YZ 位置的权重 `1 / (V样品 + V背景 + σ下限²)`。手动 σ 采用能量积分、剂量归一化后的信号单位。自动方差下限取每块晶体正方差均值的 1%；全零晶体借用其他晶体的正方差尺度。灵敏度曲线仍表示光学响应。结果摘要包含实际方差下限和主结果加权残差平方和。

   仅在有独立数据时设置背景。空白 NeXus 扫描使用相同探测器和监视器，逐能量合并计数和剂量，再匹配样品能带；空白曝光时间可单独填写。也可以在样品扫描中输入已知为空白的矩形 `[Ymin,Ymax,Zmin,Zmax]`（mm）。每个探测器像素单独估计背景，矩形内至少包含两个扫描位置；估计矩形内某点背景时排除该点。背景计数方差进入权重，共享背景引入的跨位置协方差、监视器和标定模型的不确定度未计入。原始积分值与背景估计分别保存在 `tomography_inputs.h5` 中。

   **增益与边界稳定性**位于「6 日志」。软件按各晶体的深度响应均衡分为 A、B 两组，使用已保存的 X/Y/Z 网格和该结果的加权、背景设置独立重建。全体灵敏度达到峰值的 1%、每组灵敏度至少达到当地全体的 10% 时，该深度纳入比较。每组比较 NNLS 和 TV ×0.5、×1、×2。启用增益拟合且组内有第二块晶体时，还会更换锚点，重算 NNLS 和 TV ×1。λ 采用原结果的正值；旧结果没有正 λ 时采用配置显式值或按第一组反投影计算的共同尺度。

   「查看边界对照」可切换 X、Y、Z，读取强度质心和轴向投影主峰的半高交点、厚度。边界超出共同覆盖区或扫描端点时对应数值留空。点击一行可查看该次复算的 YZ 掩膜；切换出现比例可定位只在部分方案中出现的突起。掩膜阈值统一取各体数据在共同覆盖内峰值的 50%。出现比例按复算次数统计，可分别查看已收敛方案和全部有信号试算。报告保存为 `boundary_stability.json`，再次打开结果时自动读取。
   **跨能区空间响应**默认用薄膜自身能区的谱平均像素响应拟合 PSF、质心轨迹和深度灵敏度。样品按自己的完整入射能区做梯形积分，薄膜平均响应按样品积分宽度缩放以统一模型尺度。此方式适合相同仪器几何下以固定空间响应进行反演。可在晶体光斑模型中选择「目标能区独立薄膜」，比较同一 X 位置上的质心位移、光斑半径变化和归一化像素差异。比较使用目标薄膜覆盖的样品能量点，并保存各晶体的第 90 百分位及有效 X 点数至 `spatial_response_verification.json`。请使用同一分析器设置、探测器和已对齐坐标采集验证扫描。验证报告随结果保存，不限制重建；缺少独立扫描时报告标记待验证。需要用共同能区积分时，可启用「仅积分薄膜覆盖的样品能量点」。

3. 点击 **仅校验输入**，检查扫描计划、逐帧 setpoint、完整网格、正 I0、ROI、能量范围和锚点，不创建结果。重复帧按计数和剂量池化，缺测与重叠有效 ROI 会报错。检查页可多选原编号，添加或撤销额外排除。选择独立空白时，完整能区模式仅对空白覆盖的样品能量点做背景扣除，并记录有效扣除范围。
4. 点击 **开始完整重建并保存**，后台依次提取薄膜像素、积分样品、拟合连续移动 PSF 和质心轨迹、运行联合 NNLS 与锚定增益，再执行固定增益 TV。支持取消，日志与中间文件保留。
5. **剖面分析**：查看主结果、NNLS、TV 的 XY/XZ/YZ 切片与求和投影，刻度使用实际 mm 坐标。TV 未收敛会明确标记，主结果使用 NNLS。显示缩放/对数只改变预览。
6. **三维模型**：选择主结果、NNLS 或可用的 TV 体数据，输入密度阈值并生成三角形等值面。坐标沿用重建的 XYZ 毫米坐标。左键拖动旋转，滚轮缩放，双击复位。生成等值面后可点击「保存旋转 GIF…」，设置每圈时长（2–30 秒，默认 6 秒）。软件自动取景，让模型从当前视角绕 Z 轴旋转并循环播放。GIF 为 720 × 720 像素，采用白底并隐藏坐标框、刻度和文字。

   点击下方灵敏度曲线或模型的 X 轴可选中对应截面。橙色半透明区域表示灵敏度低于所设峰值百分比的深度，默认阈值为 1%。点击「深度分辨率验证」后，程序从 `tomography_inputs.h5` 读取与样品能量范围匹配的薄箔实测数据。每次留出一个位置，用其余位置重新标定，再用样品的晶体增益、NNLS 和可选 TV 的求解规则重建该薄箔的一条 X 剖面。进度可取消。完成后，`depth_validation.json` 会保存在结果目录，下次打开时自动读取。「查看逐点报告」列出已知位置、恢复峰位、带符号偏差、半高全宽与收敛状态。半高全宽包含有限箔厚的影响。曲线上的读数注明最近实测位置和距离。
7. **日志**：默认打开运行日志。左侧可切换完整摘要、X 灵敏度、光斑模型与质心轨迹、Gram 特征值和增益与边界稳定性。“查看已有重建”可只读载入结果目录及其中保存的运行日志。

保存文件名与旧程序保持兼容：`reconstruction.h5`、`reconstruction_nnls.h5`、可选 `reconstruction_tv.h5`、`calibration.h5`、`tomography_inputs.h5`、`psf_models.json`、`solver_diagnostics.h5`、`summary.json`、`config.resolved.json`、`input_validation.json`、`provenance.json`、`run.log` 及可选 `diagnostics.png`。主数组为 float32 `reinterp_insect_ck[X,Y,Z]`，附实际 XYZ dimension scales。程序全程只读原始文件。

在「1 文件与 ROI」勾选「同时保存 Avizo 体数据（.am）」后，完整重建会在 `reconstruction.h5` 同目录生成 `reconstruction.am`。AmiraMesh 文件使用与 HDF5 主结果相同的体素值和 XYZ 毫米坐标。此选项默认关闭。

成像沿用 `计数 / (正 I0 × 曝光)` 的像素级归一化、完整 X 网格、`A=f×Δx/t_foil×Rmodel`、联合非负求解与 TV。默认主结果是以 Kapton 空间响应为基准的能量积分相对散射强度。所用能区、背景覆盖与空间响应验证状态记录在摘要中。旧方案的数值实现与实测对照见 [成像迁移记录](docs/imaging-migration.md)。

## IXS衬度成像

各步骤页可随时切换。计算按输入依赖顺序执行，打开尚未具备输入的页面时，底部会提示需先完成的步骤。

1. **数据与 ROI**。选择样品 Y/Z/能量扫描、薄膜 X/能量扫描和 ROI 方案，设置曝光及扫描循环，再点击「校验数据」检查扫描网格、剂量和 ROI。页面右上角可以载入或保存配置，也可直接打开已有的四维体素 HDF5。旧版独立三维差值 HDF5 可在数据浏览器查看。
2. **ROI标定**。在左侧设置 X 网格步长、增益锚点和求解参数，点击底部的「计算 ROI 标定」。左侧参数栏可拖动分隔线调整宽度，也可用箭头收起。薄膜用于拟合晶体空间响应，样品积分谱用于拟合相对增益。计算完成后可在右侧检查实际网格、接受及拒绝的晶体和收敛状态，再点击「下一步」。
3. **筛选晶体**。核对重建所用的晶体，点击「下一步」确认并进入四维重建。更改晶体勾选后，点击「上一步」返回第 2 步更新标定。改变 X 网格或空间求解参数也需要重新标定。
4. **四维体素重建**。按入射能量累积剂量归一化的探测器数据，计算逐能量反投影。检查每个通道的信号后，逐通道独立求解非负体素。
5. **四维结果与体素谱**。左侧集中显示谱图设置、能量坐标和谱处理选项。右侧检查通道收敛状态、切片、体素谱和瀑布图。底部显示文件状态，可将原始四维体素保存为 `/entry/bond/intensity[E,X,Y,Z]`。可选诊断包括各晶体的积分谱正演矩阵、预测、残差和同目录的 PNG。
6. **三维结果分析**。从已求解或已载入的四维结果中选择单能量强度、双能量差值 `S(Eb) − S(Ea)` 或区间积分强度，查看切片和等值面。区间积分对所选数据源的每个体素谱按实际能量间距做梯形积分，并线性插值到所选上下限。积分区间需由连续的已收敛通道覆盖，切换能量显示单位时积分值保持一致。此页还提供参考谱拟合。

求解或载入四维结果后，可在「三维结果分析 → 参考谱拟合四联图」选择 Z 切片并导入基体与目标参考谱。每个文件应包含一条谱，能量轴为能量转移（eV）。TSV 的能量列名为 `Energy Transfer (eV)`，另一列为强度。填写分析器能量后，程序对共同拟合能区内至少五个已收敛的通道逐体素拟合线性背底和参考谱，输出总强度、仅用基体谱的残差平方和、加入目标谱后得到的有符号系数，以及按系数正负阈值分区的平均谱。参考谱及参与平均的扣背底谱按拟合区间内的最大绝对强度归一化。

「四维结果与体素谱」中点击 XY 切片查看单体素谱，或在「沿 X 三维谱图」中切换曲面与瀑布。两种画法共用视角，支持左键拖动旋转、滚轮缩放和双击复位。默认能量轴为入射能量（keV），填写分析器参考能量后，可切换到能量转移（eV）。处理参数使用界面标注的单位。

- **逐体素线性扣除**适用于联合重建结果。输入一段或多段避开目标谱特征的入射能区（keV），逐体素用已收敛通道拟合直线。选择处理后的数据可对照所选体素的原始谱、扣除项和结果谱。
- **按 q 分流**读取同一样品、相同晶体标定的逐晶体宽谱，例如谱学导出的 `spectra.h5`，以实际参与重建的晶体标签匹配平均 q。全为低 q 时，使用页面上的低 q 线性区间。高 q 康普顿扣除使用单晶体四维结果。联合结果含高 q 晶体时，在「筛选晶体」仅纳入目标晶体，返回「ROI标定」关闭相对增益拟合并重新标定，再求解四维体素。
- **高 q 参数**沿用谱学的 HF 归一化、芯谱尾部和 Pearson VII 价电子轮廓。宽谱参数、体素幅度匹配区和残余直线区使用能量转移（eV）。体素幅度匹配区须由宽谱和重建共同覆盖，并避开待分析的吸收边。以该区间的面积比缩放参考轮廓，逐体素扣除价电子背底与残余直线，再回到重建的相对强度尺度。未收敛或缺少参考覆盖的通道显示为空值。
- **面积归一化**在扣除之后单独选择，使用一段连续的入射能区（keV）。面积非正或积分区间有缺口的体素无法归一化。用于比较空间强度时，可保留扣除后的相对强度；开启归一化后比较的是谱形。

「三维结果分析」和「四维结果与体素谱」共用能量通道及原始／处理后数据源。15469 示例用于验证弹性衬度和四维工作流。化学归属和 sp² 取向角需要独立的近边与标准谱验证。

## 大文件和数据精度

HDF5 通过 hyperslab 按需读取，**不会整体加载约 4.36 GiB 的测试文件**。二维预览每个轴最多 1536 个采样点，一维预览最多 100000 点；超限时按固定步长采样，界面明确标注。统计对应预览中的采样值，并非整个原始数据集。字符串数组每次预览最后一维最多 64 项，可通过切片索引翻页。

数值预览与计算使用 float64，因此绝对值超过 2⁵³ 的 64 位整数可能舍入。目前不展开复合类型、引用、可变长数值数组和嵌套数组，只提供其元数据。外部链接或压缩过滤器缺失时报告读取错误。分组浏览限制为 32 层以防循环链接。谱学计算读取完整像素、不做预览采样，采用有界帧缓冲；最多 100000 帧、2048×2048 像素，插值网格最多 200000 点。浏览器不推断扫描网格或单位；谱学单位和几何须由使用者确认。

## 编译

两平台共用 CMake，依赖 C++17 编译器、CMake ≥ 3.24、Qt ≥ 6.4（Widgets / Concurrent，运行回归测试还需要 Qt Test）和 HDF5 C / HL 开发库。成像使用仓库内的 Eigen 3.4.0 头文件（MPL2 模式）。Python 仅用于自动识别光斑。

### Windows

Windows 脚本使用 MSVC x64 和 Ninja，默认从 `miniconda3/envs/xrsabre/Library` 查找 Qt 和 HDF5。已有环境使用 `qtbase-devel=6.11.0`。构建需要 Qt 6 的 Linguist 工具 `lrelease`，用于将 `translations/xri_en.ts` 编译并嵌入程序。

```powershell
.\scripts\build.ps1 -Test
.\scripts\build.ps1 -Run
.\scripts\build.ps1 -QtRoot C:\Qt\6.8.3\msvc2022_64 -Hdf5Root C:\Libraries\hdf5 -Test
.\scripts\deploy.ps1
```

脚本只对当前进程设置编译和运行路径。也可以通过标准 CMake 指定 `CMAKE_PREFIX_PATH` 与 `HDF5_ROOT`。
完整打包前请关闭旧版 XRI 窗口，避免 Windows 锁定正在使用的 Qt 运行库。
Qt 部署使用官方 [windeployqt](https://doc.qt.io/qt-6/windows-deployment.html)，并额外解析 HDF5 与插件的 DLL 依赖。

### Linux（Ubuntu）

在 Ubuntu 上用系统 Qt 和 HDF5 构建。Windows 与 Linux 应分别使用各自的构建目录。

```sh
sudo apt install build-essential cmake ninja-build file qt6-base-dev qt6-l10n-tools qt6-translations-l10n libqt6svg6 libhdf5-dev fonts-noto-cjk
cmake -S . -B build/linux -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build/linux --parallel 2
ctest --test-dir build/linux --output-on-failure
./build/linux/XRI
```

要在当前 Ubuntu 版本生成并安装桌面软件包，运行以下命令。软件包的库依赖以打包时所用的 Ubuntu 版本为准。

```sh
cpack --config build/linux/CPackConfig.cmake -B dist/linux
sudo apt install ./dist/linux/xri-tools_*_amd64.deb
```

在 Ubuntu 26.04 上直接从源码运行时，还需安装 `qt6-svg-plugins` 以显示工具栏图标。通过 `.deb` 安装时会自动处理这个依赖。

读取较新版 HDF5 写入的文件时，Ubuntu 24.04 自带的 HDF5 1.10 可能无法解码部分数据集。可用 `-DHDF5_ROOT=/path/to/hdf5` 指定较新版 HDF5。若打包时静态链接 HDF5，请同时用 `-DXRI_BUNDLED_HDF5_LICENSE=/path/to/COPYING` 将其许可证加入安装包。
