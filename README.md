# XRI

C++17 / Qt 6 Widgets / HDF5 编写的 Windows 同步辐射数据浏览、谱学处理与三维成像软件。

本项目源代码采用 [MIT 开源协议](LICENSE)发布，Copyright (c) 2026 Hu Shiqi。第三方组件遵循各自许可证，详见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 运行

打包后双击 `dist/XRI/XRI.exe`，使用“文件 → 导入 HDF5 文件”多选，或拖入多个 `.nxs` / `.h5` 文件。
在项目目录执行以下命令，会自动打开提供的测试文件：

```powershell
.\scripts\run.ps1
```

也可以传入文件与初始数据集：

```powershell
.\dist\XRI\XRI.exe .\Data\15469_grid_scan_20261014231918_1.nxs --dataset /entry/data/D_LAMBDA --frame 1000
```

## 界面工作流程

菜单为 **文件｜数据浏览器｜ROI｜谱学｜成像｜化学键衬度分析｜帮助**。谱学、成像和化学键衬度分析在主窗口内切换工作区，再次进入时保留当前步骤、参数与结果。

1. **导入与浏览**：文件菜单可多选 HDF5；浏览器保留各文件的数据集、帧、坐标轴和显示方式。
2. **共用 ROI**：75 晶体框选、批量失效、实时 X/Y 剖面集中在同一编辑器。同一文件复用编辑状态；处理页的“选取 ROI”返回后同步方案。查看而未修改 ROI 不会清空谱学标定；修改后会使相关旧结果失效。
3. **谱学**：数据与 ROI → ROI 与掩膜 → 弹性标定 → XRS 与 I0 → 原始谱结果 → 可选拼接 → 扣背底 → 能区结果。
4. **成像**：文件与 ROI → 重建参数 → 输入与标定检查 → 剖面分析 → 三维模型 → 诊断与日志。校验后在检查页运行重建；配置与已有结果入口集中在文件准备页。
5. **化学键衬度分析**：数据与 ROI → 谱学处理与空间信息重建 → 三维体素。「四维体素与瀑布图」有单独入口。

各处理页选择数据时，可直接使用浏览器已导入的文件。左侧文件结构面板只在浏览时显示，返回后恢复原状态。原生 Windows 控件与原有处理算法保留。

全部交互图表与成像诊断 PNG 共用学术刻度：1/2/2.5/5 主刻度、次刻度、四边内向刻度、统一数字精度；曲线使用浅色虚线主网格，图例置于绘图区外。二维图像默认无网格；图上右键可切换网格与次刻度、复位范围。对数显示使用原始量值标注刻度，零和负值均保留。显示样式不改变积分、拟合或重建结果。

## 功能

根据完整文件名区分扫描格式，并在窗口标题、文件树根节点和数据摘要中显示：

| 文件名规则 | 识别类型 | 当前示例 |
| --- | --- | --- |
| `<编号>_scan_<14位时间戳>_<序号>.nxs` | scan · 一维扫描 | `14516_scan_20260917142117_1.nxs`（51 帧） |
| `<编号>_grid_scan_<14位时间戳>_<序号>.nxs` | grid_scan · 网格扫描 | `15469_grid_scan_20261014231918_1.nxs`（7056 帧） |

匹配不区分大小写，仅使用文件名，不受目录名影响。不符合规则的文件显示为“通用 HDF5 / NeXus”，仍可浏览。两种格式共用 HDF5 按需读取，维度与帧数以文件内容为准；打开新文件从第 0 帧开始。

- 原生 Windows Qt Widgets 菜单、文件对话框和可停靠面板；中文界面。“文件”集中管理导入、导出副本和关闭，“数据浏览器”集中管理预览方式、图表复位与文件结构面板。
- 按层展开 HDF5 分组，显示数据类型、维度和属性；筛选当前已加载节点。
- 标量、字符串、布尔、一维信号、二维图像和多维数组切片。
- 自由选择 X/Y 维度；底部滑块与帧输入框控制首个固定维度，支持播放。其他固定维度默认使用索引 0。
- 后台只读读取，快速切换时丢弃过期结果；探测器只读取当前帧。
- 白底学术图表、内向刻度、Viridis / Inferno / 灰度、等比例、保留符号的 log1p 显示。
- 滚轮缩放、双击复位、鼠标数值提示；显示当前切片的 min/max/mean/sum。
- 虚拟数值表，按需查看当前切片的数值。

索引从 **0** 开始。图像原点在左上，Y 向下；坐标使用数据集维度索引。

多个文件同时保留在左侧“文件列表与结构”中，每个文件有独立树根；点击其中的数据集或用“当前文件”下拉框切换。切换时恢复上次查看的数据集、坐标轴、帧索引和预览页。重复导入同一路径不会增加重复文件，重新定位到默认数据集第 0 帧。关闭当前文件后自动转到另一个已导入文件，也可关闭全部。

“文件 → 导出当前文件副本”按完整原始字节导出 HDF5 / NeXus，保留全部维度与元数据；不使用屏幕采样预览替代原数据。导出在后台分块执行，可取消；成功才提交最终文件，任何已导入的原文件均不能作为导出目标。此处为整文件副本，先前移除的图表及切片 CSV 导出保持移除。

命令行也接受多个文件，最后一个作为当前文件：

```powershell
.\dist\XRI\XRI.exe .\Data\14516_scan_20260917142117_1.nxs .\Data\15469_grid_scan_20261014231918_1.nxs
```

## 第一步：75 个分析晶体的 ROI 选取

导入文件后，选择“ROI → 选取分析晶体 ROI”，针对当前浏览文件操作；scan 和 grid_scan 共用同一个 ROI 模块。scan 的后续处理位于“谱学”菜单；grid_scan 的薄膜标定与三维联合反演位于“成像”菜单。

按参考 notebook 中的探测器分配，LAMBDA 包含 VB、HL、VU、HB 四个模块，共 60 个晶体；MINIPIX 包含 VD 模块，共 15 个。每个模块使用 A1、A2、A3 … E1、E2、E3 的标准唯一编号。参考 notebook 的历史输出中存在重复 VU 名称，本程序不复用这些重复项，也不自动将旧坐标当作已选结果。

1. 默认显示两台探测器的**全部帧原始计数叠加图**；可切换单帧，并开启 signed log1p 显示弱信号。大文件逐帧读取，不加载完整三维数组。
2. 在右侧选择晶体，然后在对应探测器图像上拖动框选。支持反向拖动、滚轮缩放、双击复位和 Esc 取消当前拖动；框选后显示晶体标签，默认跳到下一个未设置项。
3. 可修改 x1、x2、y1、y2 后点击“应用坐标 / 设为有效”；边界必须在图像内，坐标规则与 Python 切片相同：`image[y1:y2, x1:x2]`，右侧和下侧不包含在内。
4. 无法框选的晶体可用 **Ctrl 多选、Shift 连选、Ctrl+A 全选**，再点击“批量标记失效（数量）”。支持跨探测器选择；批量操作后保留所选行，已有矩形也保留，保存时 `add=false`。单选时仍可逐个标记失效并自动跳到下一项。框选、坐标编辑和“清除重选”仅作用于单选晶体。
5. 每次修改会自动保存到应用本地数据目录 `roi-drafts` 下，按原文件路径分别保存。再次打开同一文件的 ROI 窗口可继续编辑。也可“保存 ROI 方案”到独立 `.roi.json` 文件；尺寸相同的探测器可通过“加载 ROI 方案”在 scan / grid_scan 之间复用。加载会检查 75 个编号、探测器对应关系、尺寸和坐标，失败时保留当前方案。
6. 全部 75 个晶体都处于有效或失效状态后，“完成 ROI 选取”按钮才可用。

勾选窗口顶部“显示 X/Y 剖面图”，可选择探测器并输入 X（列）、Y（行）：横向剖面为 `image[Y, :]`，纵向剖面为 `image[:, X]`。直接拖动蓝色竖线调整 X、横线调整 Y、交点调整两者，坐标和曲线在拖动过程中实时更新；也可按住 Ctrl 在任一探测器图像中单击或拖动定位。Esc 停止拖动，拖出图像时位置限制在有效像素范围。远离定位线的普通拖动仍用于框选 ROI。也可单选一个已有 ROI 后点击“定位到当前 ROI 中心”。坐标范围随探测器尺寸变化，单帧切换后剖面同步更新。剖面默认显示原始计数，可独立切换对数显示；这仅改变显示比例，不改变数值，也不进行区域积分或修改晶体 ROI。

本步骤只保存矩形坐标与人工有效性标记，不执行 I0 归一化、自动寻峰、阈值掩膜、ROI 积分、拟合或成像重建。原始 `.nxs` 始终只读。先前删除的通用数据检查器、水平积分及图表/CSV 导出功能保持移除。

## 第二步：谱学处理

“谱学”菜单进入同一个主窗口工作区，通过八个步骤页处理数据，切换工作区后参数与结果仍保留。算法按提供的 `data_processing_v4.py` 与 `XRS_DataAnalysis20261013.ipynb` 中的弹性标定、掩膜、I0 修复、XRS 提取、Q 计算及插值叠加流程实现，使用原生 C++，运行无需 Python。

1. **数据与 ROI**：选择弹性参考 scan，读取该文件的共用 ROI 草稿，或载入尺寸匹配的 `.roi.json` 方案。75 个晶体均须完成框选或标记失效。添加多个 XRS 扫描，取消勾选可剔除整次扫描。grid_scan 会明确拒绝用于一维谱学处理。
2. 点击底部 **计算弹性标定**：可选择 ROI 内峰值重定位、方形窗口大小、逐晶体 X/Y 偏移与扩展，以及阈值掩膜（默认严格大于 ROI 叠加图最大值的 15%）。自动重定位默认关闭；原始人工 ROI 保留，调整后的 ROI 可另存。默认从所有涉及的 ROI 中去除重叠像素，避免重复计数；可显式关闭。掩膜页显示弹性叠加图、最终像素掩膜和 ROI 标注。
3. **弹性标定**页：查看每个晶体原 ROI / 掩膜谱、拟合曲线、峰位、FWHM、R² 及未通过原因；也可查看全部合格谱的零点对齐。支持 Lorentzian 或 Gaussian 加常数背景，默认中心 9.67–9.69 keV、FWHM ≤ 2 eV、R² ≥ 0.8。失效、无像素、平坦或未收敛的晶体不会进入叠加。
4. 点击 **提取 XRS**：逐帧积分原 ROI 与掩膜。弹性和 XRS 的 `|I0|` 归一化可分别开关。XRS 归一化开启时，可修复低于左右邻点各 0.7 倍的孤立 I0 跌落：按扫描顺序将该 I0 及整张探测器帧替换为邻点平均，再归一化。“XRS 与 I0”页可切换扫描和晶体，检查修复前后 I0 及提取谱；掩膜页可查看当前 XRS 扫描的叠加图。
5. **原始谱结果**页：角度可从弹性文件、首个 XRS 文件读取，或手动填写（degree）。几何默认晶体口径 100 mm、距离 1070 mm、晶体间隔 7°。按模组、平均 Q 范围筛选；Ctrl/Shift 多选晶体后可批量排除或纳入，人工失效及拟合未通过项无法重新纳入。
6. 点击 **计算 Q 并叠加**：按各晶体拟合中心计算 `能量转移 = (实测能量_keV − 峰位_keV) × 1000`。在所有参与曲线的共同范围内按指定步长（默认 0.2 eV）线性插值，先按晶体叠加多次扫描，再求模组谱及总谱。支持升序、降序和不等间隔能量轴。曲线选择器可查看总谱/模组谱、全部单晶体谱，以及单晶体的各扫描与叠加对比。
7. 点击 **保存谱学结果**，选择父目录后创建独立时间戳目录，包含 `spectrum_data.txt`（总谱及模组）、`spectrum_all_data.txt` 和各晶体文本谱、`spectrum_rois.txt`（拟合和 Q/dQ 表）、原始及调整后的 ROI JSON、实际像素掩膜及处理参数/能量通道/I0 修复记录。写入完成后才重命名为最终目录，已存在的目录不会覆盖。

能量输入单位为 **keV**，能量转移和 FWHM 为 **eV**，Q/dQ 为 **Å⁻¹**。`auto` 优先读取 `/entry/instrument/M_DCM_B5Energy`，缺失时使用 `M_DCM_B5Energy_readback`；也可输入完整能量/I0 数据集路径。I0 默认 `/entry/data/D_SiC_Current1`。未开启归一化时无需 I0 数据；开启后不可修复的零值或非有限值会报错。单调性、探测器尺寸、帧数与能量长度均检查，不自动合并重复能量点。

与旧程序的数值处理差异：拟合失败会明确排除，不沿用初始参数；Q 计算使用每个晶体的拟合弹性能量；公共插值范围仅由实际参与叠加的合格曲线决定，边界向内取整，避免外推。多扫描与晶体均**求和，不取平均**。改变弹性参数会清除后续结果，改变扫描或归一化只要求重新提取，改变筛选条件只要求重新叠加。计算在后台执行，支持取消。

当前真实 scan 与已有 ROI 方案已验证弹性标定；多扫描 XRS 的完整流程通过已知解析谱的合成 NeXus 数据验证。真实样品 XRS 扫描需由用户添加后再处理。

**6 可选拼接**。康普顿宽谱和近边分开采集且需要联合处理时，先载入宽谱，再选择一个或多个近边文件。按参考项目的 `workspace/stitch_compton_edge_scans.py`，用近边实测强度替换同名晶体、同一能量网格上的值。宽谱网格和晶体列表作为输出网格，容差为 1e−6 eV。替换采用原强度，两份近边数据在同晶体、同能量点重叠时需重新选择。拼接 HDF5 保存逐点来源索引和原始宽谱，重新打开后可继续以原始宽谱建立背景。

第 5 页保存的 `spectra.h5` 含逐晶体强度、平均 q、分析器能量和散射角。外部 HDF5 可在“外部 HDF5 数据集映射”中指定强度、能量和标签路径。也可直接载入 `xrs_ana` 的 `*_all_data.txt`，同名 `*_rois.txt` 会用于读取晶体几何。旧几何表可通过“补充晶体几何”载入，需要 `crystal`、`q_ave`（Å⁻¹）和 `center`（eV）列。表有 `two_theta_deg` 时直接使用，否则按宽谱能量轴和平均 q 推定散射角。重名或缺少有效 q 的晶体会显示原因。

**7 扣背底**。默认选择第 5 步的原始谱，全部晶体各自拟合并扣除线性背底。也可在此直接载入外部逐晶体 HDF5 或文本谱。只关心线性扣除时，可从第 5 步直接进入第 7 步。线性模式仅需填写拟合能区，晶体 q 和 HF 参数可省略。

需要康普顿扣除时，选择第 6 步的宽谱或拼接谱，并切换到按 q 分流的模式。设置高 q 最低值（Å⁻¹），按晶体平均 q 分流。高 q 分支选择参考项目 `xrsana/resources/data/ComptonProfiles.dat`，填写样品元素与原子计量数，例如 `Li:1, Ni:0.9, Co:0.05, Mn:0.05, O:2`。初始拟合区间来自参考项目的 NCM 示例，应按实际扫描设置。支持一段连续 HF 归一化区间、多段尾部和价电子拟合区间，以及独立的高 q 残余直线和低 q 线性区间。

高 q 分支将原始宽谱做截面修正和同窗 HF 总谱面积归一化，再扣除 HF 芯谱和尾部直线。将各晶体价电子信号映射到电子动量 `pz`，对 `qS` 取中位数，在至少三分之二参考晶体覆盖的点拟合 Pearson VII。将该轮廓按每个高 q 晶体自身的几何映射回能量轴，扣除价电子及残余直线。超出实测动量覆盖的点保留为 NaN。低 q 晶体在各自的谱上拟合并扣除直线。诊断页可查看原谱、扣除项、HF 芯谱参考与高 q 价电子轮廓。

**8 能区结果**。输入起止能量，查看单晶体或同种扣除方法的等权平均谱。也可选择按模组与 0.5 Å⁻¹ q 区间分组的结果。组平均使用完整覆盖当前能区的晶体。图使用灰色主次网格和随缩放细化的刻度。当前能区可保存为 HDF5，包含各晶体的输入谱、扣除项、结果谱及处理参数。

## 成像：薄膜标定与三维联合反演

在“文件与 ROI → 采集与物理尺度 → 扫描循环与各层帧数”中，分别设置样品的 Y、Z、DCM 和薄膜的 X、DCM。顺序从外到内排列，各轴帧数表示该轴每次循环的扫描点数。默认读取文件计划。手动顺序需与文件计划一致，手动点数按扫描范围和逐帧坐标校验。“每批读取帧数（缓存）”独立控制读取批次。循环设置随 JSON 配置保存，输入检查页显示实际顺序、各轴点数与总帧数。

打开“成像 → 打开成像处理工作区”，可导入旧 Python XRI 的 JSON 配置，或手动设置薄膜 NeXus、样品 NeXus、ROI 和采集参数。相对文件路径按配置文件所在目录解析。原配置路径若已移动，请在界面浏览选择当前文件；选择一个**尚不存在的新输出目录**，旧结果不会覆盖。

附带 `examples/imaging.15469.json` 与原 ROI 表；打包后两者位于程序旁。示例保留原来的排除与标签修正，原始文件路径需浏览选择，不包含测量数据。

1. **文件与 ROI**：支持旧 TSV ROI 表、显式排除编号/标签修正，以及当前软件的共用 `.roi.json` 方案。“选取共用 ROI”复用现有框选界面；人工失效保持排除。只使用明确选择的探测器，固定像素，不做谱学自动寻峰或阈值掩膜。
2. **重建参数**：保留全部旧参数，包括曝光、I0、薄膜厚度、探测器间距、二维高斯质量门限、样品 X 网格步长、增益锚点/边界、NNLS KKT 条件、TV λ 和停止条件。默认值与旧程序一致；曝光时间需明确核对。
3. 点击 **仅校验输入**，检查扫描计划、逐帧 setpoint、完整网格、正 I0、ROI、能量范围和锚点，不创建结果。重复帧按计数和剂量池化，缺测与重叠有效 ROI 会报错。检查页可多选原编号，添加或撤销额外排除。
4. 点击 **开始完整重建并保存**，后台执行：薄膜像素提取 → 匹配样品能量并积分 → 连续移动 PSF / 质心轨迹 → 联合 NNLS 与锚定增益 → 固定增益 TV。支持取消，日志与中间文件保留。
5. **剖面分析**：查看主结果、NNLS、TV 的 XY/XZ/YZ 切片与求和投影，刻度使用实际 mm 坐标。TV 未收敛会明确标记，主结果使用 NNLS。显示缩放/对数只改变预览。
6. **三维模型**：选择主结果、NNLS 或可用的 TV 体数据，输入密度阈值并生成三角形等值面。坐标沿用重建的 XYZ 毫米坐标。左键拖动旋转，滚轮缩放，双击复位。
7. **诊断与日志**：检查完整 X 灵敏度、各晶体质心轨迹、Gram 特征值、数值秩、收敛状态和残差。“查看已有重建”可只读载入旧版或新版结果目录。

保存文件名与旧程序保持兼容：`reconstruction.h5`、`reconstruction_nnls.h5`、可选 `reconstruction_tv.h5`、`calibration.h5`、`tomography_inputs.h5`、`psf_models.json`、`solver_diagnostics.h5`、`summary.json`、`config.resolved.json`、`input_validation.json`、`provenance.json`、`run.log` 及可选 `diagnostics.png`。主数组为 float32 `reinterp_insect_ck[X,Y,Z]`，附实际 XYZ dimension scales。程序全程只读原始文件。

在「1 文件与 ROI」勾选「同时保存 Avizo 体数据（.am）」后，完整重建会在 `reconstruction.h5` 同目录生成 `reconstruction.am`。AmiraMesh 文件使用与 HDF5 主结果相同的体素值和 XYZ 毫米坐标。此选项默认关闭。

成像沿用 `计数 / (正 I0 × 曝光)` 的像素级归一化、参考能量插值相关性方差、完整 X 网格、`A=f×Δx/t_foil×Rmodel`、联合非负求解与 TV。没有额外加入几何裁剪、阈值分割、底座清除或平滑。主结果是相对 Kapton 等效弹性散射密度，能量已积分、样品背景未扣除。详细规则、数值实现差异和实测对照见 [成像迁移记录](docs/imaging-migration.md)。

原生实现运行不需要 Python。迁移实测的 21 个接受晶体、5 个拒绝晶体和 157×21×21 网格与旧版一致，主 TV 重建的相对 L2 数组差异约 4.1×10⁻⁶；NNLS 弱响应区域的有限精度差异另有记录。

## 化学键衬度分析

1. **数据与 ROI**。选择样品 Y/Z/能量扫描、薄膜 X/能量扫描和 ROI 方案，设置曝光及扫描循环，再校验输入。可以载入已有 JSON 方案。
2. **谱学处理与空间信息重建**。核对参与计算的晶体。探测器谱按 I₀ × 曝光归一化，可选线性扣背底，或按晶体 q 值分别做低 q 线性扣除和高 q 康普顿扣除。输入 Ea、Eb（入射能量，keV），点击「计算差值投影」，在探测器上求 `S(Eb) − S(Ea)`。右侧显示所选晶体的 ROI 像素差值和（YZ）。
   在同一页设置 X 网格步长、相对晶体增益和输出位置，再点击「反演三维衬度并保存」。软件使用缓存的差值投影和薄膜标定响应做带符号反演，将结果写入独立 HDF5 文件中的 `/entry/bond/contrast[X,Y,Z]`。更改晶体、能量或扣背底设置后需重算投影。只调整空间参数时可复用投影。
3. **三维体素**。查看 XY 切片，或拖动旋转红色等值面。可调整阈值并重新生成等值面。

要查看体素谱和瀑布图，请在「谱学处理与空间信息重建」点击「重建四维体素并保存」，或从「数据与 ROI」直接打开已有的四维 HDF5 结果。

载入四维结果后，可在「三维体素 → 参考谱拟合四联图」选择 Z 切片并导入基体与目标参考谱。每个文件应包含一条谱，能量轴为能量转移（eV）。TSV 的能量列名为 `Energy Transfer (eV)`，另一列为强度。填写分析器能量后，程序对共同拟合能区内至少五个已收敛的通道逐体素拟合线性背底和参考谱，输出总强度、仅用基体谱的残差平方和、加入目标谱后得到的有符号系数，以及按系数正负阈值分区的平均谱。参考谱及参与平均的扣背底谱按拟合区间内的最大绝对强度归一化。

空间 PSF 与相对晶体增益跨能量共用，各能量通道单独反演。HDF5 保存 `/entry/bond/intensity[E,X,Y,Z]`、物理坐标、收敛状态、X 灵敏度和诊断，可从第 1 步直接打开已有结果。可选的积分谱诊断将各晶体正演矩阵、预测和残差写入 `/entry/bond/band_diagnostics`，并可在同目录保存诊断 PNG。

「四维体素与瀑布图」中点击 XY 切片查看单体素谱，或在「沿 X 三维谱图」中切换曲面与瀑布，两种画法共用视角，支持左键拖动旋转、滚轮缩放和双击复位。默认能量轴为入射能量（keV），填写分析器参考能量后，可切换到能量转移（eV）。处理参数使用界面标注的单位，切换显示坐标时可继续查看同一处理结果。

- **逐体素线性扣除**适用于联合重建结果。输入一段或多段避开目标谱特征的入射能区（keV），逐体素用已收敛通道拟合直线。选择处理后的数据可对照所选体素的原始谱、扣除项和结果谱。
- **按 q 分流**读取同一样品、相同晶体标定的逐晶体宽谱，例如谱学导出的 `spectra.h5`，以实际参与重建的晶体标签匹配平均 q。全为低 q 时，使用页面上的低 q 线性区间。高 q 康普顿扣除使用单晶体四维结果。联合结果含高 q 晶体时，在谱处理页仅纳入目标晶体并关闭相对晶体增益拟合，再以新文件名重建。
- **高 q 参数**沿用谱学的 HF 归一化、芯谱尾部和 Pearson VII 价电子轮廓。宽谱参数、体素幅度匹配区和残余直线区使用能量转移（eV）。体素幅度匹配区须由宽谱和重建共同覆盖，并避开待分析的吸收边。以该区间的面积比缩放参考轮廓，逐体素扣除价电子背底与残余直线，再回到重建的相对强度尺度。未收敛或缺少参考覆盖的通道显示为空值。
- **面积归一化**在扣除之后单独选择，使用一段连续的入射能区（keV）。面积非正或积分区间有缺口的体素无法归一化。用于比较空间强度时，可保留扣除后的相对强度；开启归一化后比较的是谱形。

载入四维数据后，「三维体素」也可选择单能量强度或从四维体素取双能量差值，能量通道和原始／处理后数据源与「四维体素与瀑布图」共用。切回原始体素时仍保留处理结果。15469 示例用于验证弹性衬度和四维工作流。化学归属和 sp² 取向角需要独立的近边与标准谱验证。

## 大文件和数据精度

HDF5 通过 hyperslab 按需读取，**不会整体加载约 4.36 GiB 的测试文件**。二维预览每个轴最多 1536 个采样点，一维预览最多 100000 点；超限时按固定步长采样，界面明确标注。统计对应预览中的采样值，并非整个原始数据集。字符串数组每次预览最后一维最多 64 项，可通过切片索引翻页。

数值预览与计算使用 float64，因此绝对值超过 2⁵³ 的 64 位整数可能舍入。目前不展开复合类型、引用、可变长数值数组和嵌套数组，只提供其元数据。外部链接或压缩过滤器缺失时报告读取错误。分组浏览限制为 32 层以防循环链接。谱学计算读取完整像素、不做预览采样，采用有界帧缓冲；最多 100000 帧、2048×2048 像素，插值网格最多 200000 点。浏览器不推断扫描网格或单位；谱学单位和几何须由使用者确认。

## 编译

需要 MSVC x64 C++ 开发工具、CMake ≥ 3.24、Ninja、Qt ≥ 6.5（Widgets / Concurrent 开发包；回归测试还需要 Qt Test）和 HDF5 C / HL 开发库。成像的 Eigen 3.4.0 头文件已包含在 `third_party/eigen3`（MPL2 模式）。本机脚本默认使用已有的 `miniconda3/envs/xrsabre/Library`；匹配的 Qt 开发包是 `qtbase-devel=6.11.0`。运行时不依赖 Python。

```powershell
.\scripts\build.ps1 -Test
.\scripts\build.ps1 -QtRoot C:\Qt\6.8.3\msvc2022_64 -Hdf5Root C:\Libraries\hdf5 -Test
.\scripts\deploy.ps1
```

脚本只对当前进程设置编译和运行路径。也可以通过标准 CMake 指定 `CMAKE_PREFIX_PATH` 与 `HDF5_ROOT`。
完整打包前请关闭旧版 XRI 窗口，避免 Windows 锁定正在使用的 Qt 运行库。
Qt 部署使用官方 [windeployqt](https://doc.qt.io/qt-6/windows-deployment.html)，并额外解析 HDF5 与插件的 DLL 依赖。
