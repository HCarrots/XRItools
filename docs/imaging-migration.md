# 成像流程迁移记录

原程序：用户提供的 `python/xrsabre/XRI`，Git 提交 `b968163977639821da5dac6da4abe3327d4cfddc`，迁移时工作区干净。依据 `xri/calibration.py`、`nexus.py`、`spatial.py`、`solver.py`、`pipeline.py` 及随附处理逻辑、输入输出参数说明，移植至原生 C++17。没有修改旧 Python 工程、原始数据和旧结果。

## 保留的处理逻辑

1. 解析 `P.grid_scan` 的薄膜 XE 和样品 YZE 计划，使用逐帧 setpoint 最近匹配。位置容差 1e−6 mm、能量容差 1e−8 keV；重复帧合并计数与剂量，缺测报错，不按原顺序盲目 reshape。
2. 正且有限的 I0 × 显式曝光构成剂量。不套用谱学的 abs(I0) 或异常帧替换。ROI 内固定像素保持行优先顺序，不把晶体先积分为一个强度。
3. 薄膜能量先匹配样品计划能量，再用同一套梯形积分权重。方差使用合并后的有效参考权重再平方，保留插值引入的相关性；禁止外推。
4. 椭圆相关二维高斯加常数背景，沿用相同的候选峰高、R²、中心距边界、最少观测数、宽度及轨迹 RMS 门限。按幅度加权拟合线性质心轨迹，取幅度、宽度及相关系数中位数，生成连续移动单光斑；拟合偏置不进入正演核。
5. X 网格使用显式样品步长或合格晶体样品长度/探测器像素中位数，覆盖完整标定区间并居中排列。不将薄膜位置数量固定为 X 层数，不按灵敏度裁剪。
6. `A = f × Δx / t_foil × Rmodel`。联合所有晶体的 Gram 与右端项，批量加速投影梯度 NNLS，按投影 KKT 停止；H 和右端项使用同一相对 1e−14 数值模式规则。
7. 增益闭式交替更新、给定正边界、明确锚点固定为 1，最后按最终增益重新求 NNLS。锚点未通过 PSF 检查会报错，不自动替换。
8. 固定最终增益，以 NNLS 为初值进行 Condat–Vu 非负各向同性 TV。使用实际 XYZ 间距、零前向边界及精确伴随。保留显式 λ 和原来的相对尺度启发式，分别检查原始和对偶变化。
9. TV 收敛才作为主结果，否则主结果回退 NNLS，保存 TV 最后迭代并标记未收敛。没有增加裁剪、阈值分割、对称清理、底座清除或平滑后处理。
10. 保留主结果名 `reinterp_insect_ck`、float32、XYZ 坐标及 dimension scales，NNLS/TV、像素中间量、PSF、预测与残差、灵敏度、Gram 特征值、配置和溯源。目录已存在时拒绝覆盖；失败保留中间文件与日志。

## 界面与实现适配

- “成像”菜单打开同一原生 Qt 工作窗口；支持旧 JSON 配置和 TSV ROI，新增对共用 `.roi.json` 的适配。共用方案按标准 0～74 原编号生成键，人工失效保持排除；只读取明确选择的探测器。不存在自动合并 LAMBDA / MINIPIX。
- 旧 TSV 的平移/扩展显式应用，保留原编号与原标签；共用 ROI 的坐标直接使用。成像不使用谱学阈值掩膜。有效矩形重叠会报错。
- 支持后台计算、取消、运行日志、逐晶体质量表，以及物理 mm 坐标的 XY/XZ/YZ 切片和求和投影。显示方式不会改变保存的体数据。
- C++ 使用 Eigen 3.4.0，二维高斯采用带相同参数边界的阻尼最小二乘；原版使用 SciPy 的有界拟合。因此数值结果不承诺逐位相同，验收使用物理量、质量门限、残差及浮点容差。
- 不依赖 Python 运行时，不调用旧脚本或旧缓存进行重建。旧缓存仅用于本次独立验证。诊断 PNG 使用 Qt 绘制，版式与配色不影响数值。
- 内存限制显式报错：探测器单轴最多 4096，X 恢复网格 2～4096 个单元，总体素最多 1600 万；像素缓冲有界，读取批次可因内存上限缩小。限制不会通过删坐标或自动降采样满足。
